Средние показатели по тегам

Только теги, входящие в Каталог ОПИК. Все значения — средние за предыдущий период. Нажмите на заголовок столбца, чтобы отсортировать.

Как считаются показатели

    Колонки выгрузки

    Сопоставьте поля дашборда со столбцами вашей выгрузки. Обязательны только дата создания и теги — остальное включает дополнительные показатели, если данные есть.

    Столбцы с тегами

    Можно отметить несколько столбцов — теги из них объединяются. Значения внутри ячейки разделяются символами ; , | или переводом строки.

    Каталог ОПИК

    Одна строка — один тег. Необязательный код отделяется вертикальной чертой: ОПИК-04 | Возврат средств. Аналитика строится только по этим тегам; всё остальное попадает в счётчик «вне каталога».

    Все значения тегов, встреченные в загруженной выгрузке. Отметьте те, что входят в Каталог ОПИК — отмеченные заменят текущий список.
