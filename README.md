# Astra

## Статистика по задачам ОПИК

`opik-dashboard.html` — дашборд в одном HTML-файле, работает без интернета. Скачайте файл,
откройте в браузере и загрузите две выгрузки из CRM:

1. **Исторические данные** — файл с правильными датами закрытия (например, `2026_ОПИК.xlsx`).
2. **Актуальная выгрузка** — выгрузка на сегодня (например, `2026.xlsx`).

Файлы читаются прямо в браузере и никуда не отправляются. Последние загруженные файлы
и настройки запоминаются в браузере. Поддерживаются `.xlsx`, `.csv` и выгрузка `.xls` из CRM
в виде HTML-таблицы.

### Что показывает

- **Сейчас: рассмотрение и работа** — незавершённые задачи в стадиях канбана «Рассмотрение»
  и «Работа». Для каждой задачи есть прогноз: когда её возьмут в работу и когда завершат.
- **Сроки по тегам** — по завершённым задачам: ожидание (начало работы − создание),
  выполнение (закрытие − начало работы) и полный цикл. Выводимые теги выбираются в фильтре.
- **Запросы колодцев** — запросы от сделки (графа «Сделка» заполнена) и от заказчиков,
  по колодцам, месяцам и менеджерам.
- **Задачи, поставленные КАМ** — задачи, где менеджер колодца указан постановщиком,
  и их типы (теги).

### Как сводятся файлы

- Основа — актуальная выгрузка.
- Если в ней исполнитель — Дмитрий Скакун, а в исторических данных задача уже была закрыта
  и её постановщиком или исполнителем была Инга Бурда или Алёна Ефремова, то дата закрытия
  и участники берутся из исторических данных.
- Завершённые задачи исключённых сотрудников, которых нет в актуальной выгрузке,
  добавляются из исторических данных.

Колодцы и менеджеры взяты из `Ответственные.docx`. Их можно изменить в настройках дашборда
или загрузить обновлённый `.docx`.
