# Astra

## Конструктор воронки — `funnel-constructor.html`

Схема «Единая воронка: от обращения до выигрыша» с встроенным редактором. Файл самодостаточный: откройте его в браузере.

- Кнопка **«Редактировать»** открывает конструктор справа (на телефоне — снизу).
- **Стадия** — название, подпись, группа, номер и ширина полосы; ответственный и свой цвет; метка, плашка-статус, пунктир, источник; блоки описания (текст, список полей, ответственный) и поля внутри списков — с цветом, признаком «по желанию» и порядком. Добавить, дублировать, переместить или удалить стадию можно здесь или кнопкой «+ Добавить стадию» под группой.
- **Общее** — тексты страницы, варианты переключателя («Как сейчас» / «По новому ТЗ»), ответственные и их цвета для светлой и тёмной темы, группы стадий.
- **Файл** — скачать HTML с конструктором или только для просмотра, экспорт и импорт JSON, возврат к версии из файла.

Изменения сохраняются в браузере автоматически, а в файл попадают после «Файл → Скачать HTML» (или Ctrl+S): скачанный файл заменяет исходный. Отмена и повтор — ↶ / ↷ или Ctrl+Z / Ctrl+Shift+Z. В версии «только для просмотра» конструктор включается добавлением `#edit` к адресу файла.
